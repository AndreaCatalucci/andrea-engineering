# Non-Software Ideation

Read this only for a subject with no software surface. The evidence, generate
then critique order, basis rules, rejection record, and final document stay the
same; examples and evaluation use the subject's own domain.

## Choose depth

- **Quick:** select `non-software-quick`; the root generates the compact round
  without generation subagents, then uses the normal checked-file pipeline and
  verifier.
- **Standard:** select `non-software-standard` and the normal verifier.
- **Full:** select `non-software-full` and add the extra critic.

Use Standard unless the request clearly asks for an immediate starter set or
deep exploration. State the chosen fleet before generation.

## Apply the shared process

Choose 3-5 topic areas when the subject has distinct parts; skip them for a
single name, tagline, plot, or other atomic output. Use the same six frames from
`divergent-ideation.md` in domain-native language. For example, “pain” may mean
an awkward decision or weak narrative, while “leverage” may mean a choice that
improves many later options.

At Standard or Full depth, follow `divergent-ideation.md` with assignment kind
`universal`, the selected dispatch entry, and the same candidate file and
receipt rules. Keep every move inside the subject's identity. Generate all
candidates before critique and add no final-document prose to raw files.

For Quick, the root performs the generation step itself. It creates one
`universal` assignment for the compact round, writes the strict expected-
assignment manifest, writes and seals the candidate file with `--expected`, and
accepts the receipt with the same manifest. It merges only those accepted
projections, writes their source registry, and seals consolidated candidates
with `--sources`. Quick then follows the normal verifier, arbitration, and
delivery path; only generation subagents are skipped.

After merge, allow 3-5 cross-cutting combinations and apply the recovery entry
to empty areas. Continue through `post-ideation-workflow.md`; verification uses
the supplied material and web research rather than repository reads.
