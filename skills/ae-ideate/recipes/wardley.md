# Wardley

Start from the user need named by Impact Mapping.

1. Name the few capabilities in the value chain that would satisfy that need.
2. Place each roughly on the evolution axis: genesis, custom-built, product, or commodity.
3. Name the implications: what should differentiate, what to reuse or buy, where dependencies may shift, and where an option competes on a commodity.

State each stage in a short clause. Fold only the conclusions that change the thesis, alternatives, riskiest assumptions, or open questions into the Opportunity Brief. The Wardley map is working material.
