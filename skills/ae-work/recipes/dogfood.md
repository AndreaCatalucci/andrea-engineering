# Dogfood

Identify the changed or requested journey and use the real interface from its natural entry point. Concentrate on failures that block or confuse that journey.

Capture a focused reproduction for each material issue. A fix request includes clear in-scope regressions; a report request returns the observations. Re-run the affected part of the journey after a fix.

Return the journey exercised, material issues, fixes made, and any part awaiting access or data. Create a durable QA report on request.
