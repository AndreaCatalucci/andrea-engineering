# Learn

Preserve one lesson that will materially help future work in this repository.

Search `docs/solutions/` for a direct duplicate, then create or update the nearest document with:

- the belief, experiment, or assumption;
- what reality showed;
- the lesson and why it will change later work;
- where it applies and its boundaries;
- the most useful code or documentation pointers.

Use ordinary Markdown and the project's language, centered on reusable project knowledge.

Keep capture scoped to the nearest solution document. One trajectory change is one lesson.

Load [`garden.md`](recipes/garden.md) for an explicit `garden [scope]` request. A normal learning may recommend a narrow garden scope for a future run.

Before finishing, run the `unslop` skill.
