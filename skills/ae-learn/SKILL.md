# Learn

Preserve one lesson that will materially help future work in this repository.

Use a recently solved, verified problem. Search `docs/solutions/` for a direct duplicate, then create or update the nearest document with:

- the context and symptom;
- the actual cause;
- the solution and why it worked;
- where the lesson applies and its boundaries;
- the most useful code or documentation pointers.

Use ordinary Markdown and the project's language, centered on reusable project knowledge.

Run learning from an explicit request and keep capture scoped to the nearest solution document.

Load [`garden.md`](recipes/garden.md) for an explicit `garden [scope]` request. A normal learning may recommend a narrow garden scope for a future run.

Before finishing, run the `unslop` skill on the written document.
