# Watch PR

Observe the requested PR's current revision, required checks, unresolved review feedback, and merge status through an available mechanism that reports those facts. Follow meaningful changes until the PR is merge-ready, closed, merged, or needs a human decision. Check that results apply to the current revision; executor completion alone does not establish PR readiness.

Active babysitting fixes clear in-scope CI failures or feedback, pushes the correction, and continues. Observation requests report state as it changes.

Return the latest check state, unresolved feedback, changes made, and the exact decision needed when blocked. If continued observation is unavailable, report the latest observed state and that limitation. Repeated non-convergence completes the watch with that decision surfaced.
