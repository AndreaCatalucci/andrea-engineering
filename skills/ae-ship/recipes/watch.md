# Watch PR

Use the product's task-waiting mechanism to follow the requested open PR. Watch checks and new review feedback until it is merge-ready, closed, merged, or needs a human decision.

Active babysitting fixes clear in-scope CI failures or feedback, pushes the correction, and continues. Observation requests report state as it changes.

Return the latest check state, unresolved feedback, changes made, and the exact decision needed when blocked. Repeated non-convergence completes the watch with that decision surfaced.
