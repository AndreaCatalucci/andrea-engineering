# PR feedback

Fetch unresolved review threads and comments for the requested PR. Focus on actionable requests that remain current and align with product intent.

For actionable feedback, inspect the code, make the smallest coherent fix, run the directly relevant existing check, then commit and push when the user's request authorizes it. Reply with what changed and resolve addressed threads.

Group comments with one root cause into one fix. Surface the decision when feedback requires changing intended behavior or reaches non-convergence.
